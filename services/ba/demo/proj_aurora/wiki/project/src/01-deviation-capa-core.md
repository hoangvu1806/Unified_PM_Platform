# Aurora CAPA Core Rules

## Rules
- Held lots stay segregated; sellable stock stays separate from held lots.
- Hold release requires ACT-QA signature; ACT-WH alone cannot release a held lot.
- Recall class is None, Class Two, or Class One; ACT-REG proposes; ACT-PM confirms Class One.
- ACT-LOG executes recall shipments only after Class One or Class Two is confirmed.
- ACT-PO approves the BA package; agents never approve wiki pages.
- Deviation case binds one batch lot identity and one originating plant.
- Severity is Critical, Major, or Minor; only ACT-QA may set or change severity.
- Critical severity requires ACT-PM acknowledgment before CAPA close.
- CAPA starts two tracks in parallel: ACT-LAB and ACT-PROD; both complete before effectiveness review.
- ACT-WH places inventory hold when severity is Critical or Major.
- ACT-REG reviews every Critical case before market action.
- Missing lab result or missing production timeline prevents CAPA close.
- When lab shows adulteration risk, severity escalates to Critical before recall class.

## Org
- ACT-QA, ACT-PROD, ACT-LAB, ACT-WH, ACT-REG, ACT-PM, ACT-LOG, ACT-PO.
