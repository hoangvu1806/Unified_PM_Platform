# Aurora Recall Class Decision Matrix

## Rules
- Class None: no market withdrawal; close after CAPA effectiveness.
- Class Two: limited withdrawal for named distributors; ACT-REG proposes, ACT-QA concurs.
- Class One: full market withdrawal; ACT-REG proposes, ACT-PM confirms, ACT-LOG ships notices.
- When lab result shows adulteration risk, severity escalates to Critical before recall class.

## Constraint
- Public statements about recall class are out of BA package scope; only internal case fields.
