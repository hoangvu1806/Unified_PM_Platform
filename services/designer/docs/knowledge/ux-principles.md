# Product-specific UI knowledge

## Information hierarchy
Every screen needs one dominant user job. Order content by decision sequence, keep primary
actions visually singular, and reduce secondary controls before reducing explanatory text.

## Responsive composition
Responsive design changes hierarchy, not only width. Collapse parallel desktop regions into
a meaningful mobile sequence. Preserve labels, avoid horizontal page overflow, and keep
interactive targets at least 44 by 44 pixels.

## Distinctive direction
Derive composition, copy, imagery, and one signature treatment from the product subject.
Avoid default gradient heroes, arbitrary numbered cards, repeated three-column sections, and
decorations that do not communicate product meaning.

## Forms and dense tools
Group fields by user decision, put validation next to the affected control, preserve entered
data on failure, and use progressive disclosure for rare settings. Dense data screens should
prioritize scanning, comparison, and stable alignment.

## Commerce and media
Use imagery to answer a concrete purchase or discovery question. Product grids need stable
aspect ratios, readable prices and states, and actions that remain associated with the item.

## Accessibility
Maintain readable contrast, visible focus, explicit labels, logical reading order, and useful
empty and error states. Do not encode state through color alone.
