# Storyset education illustration samples

This folder contains five editable SVG variants of Storyset's **Studying** illustration, downloaded from the official Storyset pages. The subject stays the same so designers can compare the visual language across Storyset styles.

| Style | File | Source |
| --- | --- | --- |

| Bro | `storyset/bro/studying.svg` | https://storyset.com/illustration/studying/bro |
| Amico | `storyset/amico/studying.svg` | https://storyset.com/illustration/studying/amico |

## Attribution and use

These are free Storyset illustrations. Storyset requires attribution for free use, including personal and commercial projects. For shipped previews or product UI, include credit such as **“Illustration by Storyset”** with a link to https://storyset.com/education. See the [Storyset FAQ](https://storyset.com/faqs) and [Terms](https://storyset.com/terms) for current conditions. Do not distribute these SVGs as a standalone asset pack or stock library.

The SVGs can be edited; Storyset's editor also allows recoloring and choosing hidden, simple, or detailed backgrounds. The Designer style-preview flow now offers matching catalog entries to the art director, embeds the chosen SVG locally for rendering, and displays a Storyset credit on the preview card. If the user chooses that direction, its asset reference is carried into the UI-spec prompt.
